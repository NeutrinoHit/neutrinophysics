# Два статичных рисунка к лекции 11

1. `one-sheet.svg` — поля в одной точке за тонким слоем как функции времени.
   Голубая кривая — падающее поле, коралловая — поле зарядов слоя, золотая —
   их сумма. На общей шкале отмечены максимумы падающего и прошедшего полей.
2. `many-sheets.svg` — пространственный срез поля двадцати слоёв в один момент.
   Пунктир показывает волну без вещества. Максимумы рассчитанного поля внутри
   образца ближе друг к другу; за образцом восстанавливается вакуумная длина
   волны и сохраняется фазовый сдвиг. Короткие штрихи обозначают позиции слоёв.

PNG-файлы содержат те же рисунки для отдельного просмотра. В лекцию включены
векторные SVG. Расчёт и оформление — DN.

## Физическая модель

Обычная трёхмерная электродинамика с плоской симметрией. Электрическое поле
поперечно направлению распространения z. Каждый тонкий слой — однородный
поверхностный ток в поперечной плоскости, а не отдельная точечная частица.
Условие исходящих волн даёт поле слоя

    E_sheet(z,t) = -Z_0 K(t-|z|/c)/2,
    K = N_s q dx/dt.

Связанные заряды подчиняются уравнению Лоренца с полным локальным полем.
При временном соглашении exp(-i omega t) вводим безразмерный отклик слоя

    beta = S / (1-u²-i gamma u),
    u = omega/omega_0,
    S = omega Z_0 N_s q² / (2m omega_0²).

Здесь gamma задаётся в единицах omega_0. В `config.toml` u=0,6,
gamma=0,01 и S=0,1. Эти параметры совпадают с исходными настройками шага 4
при плотности 0,5. Длина измеряется в вакуумных длинах волн, k=2pi.
Для одного слоя

    t = 1/(1-i beta),  r = t-1,
    E_in = Re[exp(-i omega t)],
    E_sheet = Re[r exp(-i omega t)],
    E_out = Re[t exp(-i omega t)].

Общий нуль времени на рисунке произволен. Показан участок колебания вокруг
одного максимума. Относительные амплитуды и фазы не изменяются для рисунка.
Фазовое запаздывание максимума равно arg(t)/omega, здесь около 0,025 периода.
Это фазовая задержка монохроматического колебания, не время задержки фронта.

В стопке между соседними слоями поле имеет вид A exp(ikz)+B exp(-ikz).
На каждом слое E непрерывно, а производная удовлетворяет условию

    E'(z+) - E'(z-) = -2 k beta E(z).

Обратный перенос от условия отсутствия входящей волны справа совпадает
с алгоритмом `solveStack` в соседнем `refraction_origin.js`. Переотражения и
слабое поглощение учтены. В этой версии центры слоёв находятся посередине
каждой ячейки. Расстояние между слоями a=1/16, число слоёв 20, толщина 1,25.
Ни одна кривая не строится по заранее заданному показателю преломления.

Для пространственной моды периодической стопки

    cos(q a) = cos(k a) - beta sin(k a),
    n_phase = Re(q)/k ≈ 1,343.

Средняя фазовая длина волны равна 2pi/Re(q) ≈ 0,745 lambda_0.
Скобка внутри образца стоит на двух настоящих максимумах мгновенного поля:
их расстояние около 0,740 lambda_0. Разница около 0,6% отражает дискретность
слоёв и конечность слабо поглощающего образца. Формула n=lambda_0/lambda
описывает макроскопическую фазовую длину волны; локальная оценка по двум
максимумам является приближением. Поэтому на основном рисунке дано
сравнение длин волн, без избыточной численной точности.

## Воспроизведение и проверки

Из этого каталога:

    python make_figures.py

Программа создаёт два SVG, два PNG и `calculation.json`. Требуются NumPy,
SciPy и Matplotlib. Все параметры задачи находятся в `config.toml`.
При построении проверяются аналитический ответ одного слоя, непрерывность
поля, скачок производной, энергетический баланс с поглощением и унитарность
для слоя без потерь. Скобки и точки на графиках вычислены из решения.

Суммарные коэффициенты для стопки: отражение около 6,96%, прохождение
88,76%, поглощение 4,28%. Численные невязки условий на слоях и баланса
энергии порядка 10^-15.

Физическая основа: [Фейнмановские лекции, I, глава 31](https://www.feynmanlectures.caltech.edu/I_31.html).
