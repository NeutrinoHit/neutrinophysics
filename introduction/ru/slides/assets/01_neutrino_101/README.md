# Ресурсы лекции 01

Медиафайлы извлечены из исходной презентации
`introduction/slides/Introduction.key`. Старые Keynote- и HTML-версии остаются
неизменными и служат визуальным эталоном переноса.

QMD-фрагменты содержат только композиции, специфичные для слайдов. Основной
текст, определения и формулы находятся в `01_neutrino_first_contact.qmd`, чтобы их было
проще использовать при подготовке учебника.
