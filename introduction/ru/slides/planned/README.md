# Лекции готовятся

Здесь сохранены материалы DN к лекциям 16–35. Они не входят в опубликованный
русский раздел слайдов. Номера сохранены по программе курса.

После записи и проверки лекцию возвращают в основной раздел командой
из корня репозитория:

~~~bash
make publish-lecture LECTURE=16 MAP_ROOT=/Users/dmitrijnaumov/NeutrinoHit/neutrinohit-map
~~~

Команда переносит исходник, восстанавливает пути к общим ресурсам и
возвращает сохранённые строки в каталоги курса и центрального сайта.
Затем нужно проверить сборку, закоммитить изменения в двух репозиториях
и выполнить push. Сам перенос сайт не публикует.
