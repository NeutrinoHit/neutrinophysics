# Введение в физику нейтрино

В папке хранится структура вводного курса:

- русская Quarto-книга лежит в `ru/book/` и использует общую книжную основу
  NeutrinoHit с локальной адаптацией для тематических разделов, биографий и
  медиа;
- русские QMD-слайды лежат в `ru/slides/`, последовательно пронумерованы
  от `01` до `35` и используют формат 16:9;
- английские QMD-заготовки слайдов лежат в `en/slides/`;
- RevealJS-настройки находятся прямо в YAML-шапках QMD-заготовок, чтобы
  индексы `ru/slides/index.qmd` и `en/slides/index.qmd` оставались обычными
  HTML-страницами.

Для рендера выполнить из корня репозитория:

```bash
quarto render
```

Книга собирается через Makefile репозитория:

```bash
make book-html
make book-epub
make book-pdf
```

## Интерактивные апплеты

- Содержательный QMD-фрагмент хранится рядом с лекцией в
  `ru/slides/assets/<lecture-slug>/`.
- RevealJS-слайд включает этот фрагмент напрямую через
  `{{< include ...qmd >}}`; HTML-страницу апплета внутрь слайда не встраивают.
- Отдельная страница `ru/applets/<name>.qmd` включает тот же фрагмент и
  добавляет навигацию, описание и ссылку на исходный код.
- В книге используется общий блок `.interactive`: в HTML он встраивает
  страницу апплета, в EPUB указывает её публичный URL, а в PDF показывает
  постер и QR-код.

Новые русские QMD-слайды публикуются по адресу вида
`https://neutrinohit.github.io/neutrinophysics/introduction/ru/slides/04_neutrino_mass_kinematics.html`.
